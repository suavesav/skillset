# Contributing

## Issues and ideas

Report bugs and propose ideas through the issue forms. Questions and
open-ended ideas go in [GitHub Discussions](https://github.com/suavesav/skillset/discussions).

## Pull requests

Not accepted at this time. `main` publishes the Claude Code plugin
marketplace and the hosted viewer directly, so the maintainer is the only
committer. PRs opened from other accounts are closed automatically. This may
change later.

## Proposing a skill

Open an Idea issue with:

- the skill's name
- which team bundles it belongs to
- its `[[knowledge]]` / `[[agent]]` dependencies
- the trigger phrases

See `CLAUDE.md` for the file format.
